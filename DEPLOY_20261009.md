# Novelty Library — Drafts, Book Reservations & Home Stories

1. Run `supabase/migrations/20261009_drafts_reservations_and_story_home.sql` in the Supabase SQL Editor once.
2. Deploy/redeploy the frontend from this project.
3. No Google Sheets/App Script changes are required for this feature set.

## What changed

- Save Draft opens a naming popup. Blank name falls back to the book title or `Draft [n]`.
- Each account can keep up to 5 server-side review drafts.
- Load Draft is now a dropdown containing that account's saved drafts.
- Reserve a Book is a teal action above the submission form. It collects book name and optional author and clearly states that admin approval is required.
- Reservation requests create user/admin notifications; admin acceptance notifies the requester that the book is reserved.
- Admin Book Reviews gets a `Reserved Book Reviews List` tab between Publishing Queue and Posters, with Pending / Accepted / Rejected views and a direct `Add Reserved Book` action for admins.
- Users cannot submit a book that already appears in the accepted master list / approved review list or has an accepted reservation. The exact user-facing messages are `This book is already reviewed. Please pick another book.` and `This book is already reserved. Please pick another book.`
- The 24-hour Stories rail is moved into the Home hero, between the `What book broke your brain this month?` area and the analytics strip.
