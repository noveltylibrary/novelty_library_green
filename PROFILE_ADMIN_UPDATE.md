# Novelty Library profile/admin update

- Admin can set saved placeholders for short answer, paragraph, number, year and URL profile questions.
- Image-upload profile questions support admin-set image slot count, maximum file size, and maximum width/height in pixels.
- Edit no longer scrolls the document to the bottom; the editor scrolls into view and is sticky on desktop.
- Admin Pages Moderation has two top-level modes: Editor (Review Guidelines, About, Privacy, Terms) and Profile Page (sections, questions and card preview).
- Profile page questions use three columns at xl desktop widths.
- Admin profile view includes a card-preview mode showing questions marked for the profile card.
- Review Guidelines uses a native, richer branded UI with no Blogger iframe.
