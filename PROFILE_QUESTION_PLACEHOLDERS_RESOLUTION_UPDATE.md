# Profile Question Placeholder + Image Resolution Update

Admins can now set an answer placeholder for short answer, paragraph, number, year, and URL profile questions.

Image-upload questions now support configurable:
- number of image slots;
- maximum file size;
- maximum width in pixels;
- maximum height in pixels.

The browser resize/upload path enforces the configured maximum dimensions before storage upload.

The profile question editor no longer scrolls to the bottom when Edit is clicked. It scrolls the editor itself into view and makes the editor sticky on desktop.

Profile questions are shown in three columns at xl desktop widths.
