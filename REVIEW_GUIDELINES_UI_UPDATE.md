# Review Guidelines UI Update

The Submit Reviews > Review Guidelines modal no longer embeds the external Blogger page in an iframe.

The supplied Novelty Library guide HTML is rendered directly inside the web app as an in-app, scrollable UI. It preserves the guide's visual structure, hero section, accordions, cards, images, links, and contact information, with an accessible close button and Escape-key support.

The source page's submission-form CTA was redirected to the internal `/submit` route, and the old modal-level "Open full page" Blogger link was removed.

Source content basis: user-provided `Pasted text.txt`.
