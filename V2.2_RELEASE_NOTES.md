- Author names: the surname (and any middle names) now stay on the same line as the first name, smaller, never split mid-word. Titles such as Sir, Madam, Mr, Mrs, Miss, Dr are set small before the name and are never used as the first name or the avatar letter.

- Author page: bottom heading is now "Reviews of Books by <author>".
- Taste Match SE: when no review matches the "Can't spell it?" search, Open Library is asked what was meant. If that spelling matches one of our reviews it is shown, otherwise the real title is named as not yet reviewed.
- vercel.json: connect-src now allows https://en.wikipedia.org (Open Library was already allowed). No database changes.
