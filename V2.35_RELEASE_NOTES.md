# v2.35
- Reading Challenge counts books by the Submit form's "Date of review" (review_date) falling in the current year. Reviews without that date are not counted automatically.
- New manual entry under Reading goals: [-] number [+]. The number can go up freely (reviews posted later, books never reviewed) but never below the automatic count. The difference is saved as `extra` in `profile_answers.__reading_challenge` and is added to the widget count everywhere. No SQL.
