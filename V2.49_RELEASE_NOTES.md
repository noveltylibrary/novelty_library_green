# Novelty Library 2.49

Explore → Enigma, built on 2.48.

- **LexiWord is the classic five-letter game**: six tries, every guess must be a real English word (built-in list, then an open dictionary for rarer words), tiles flip to show correct spot, other spot or no match.
- **Answers and puzzles are chosen per reader by Taste Match SE** from the reader's device, content preferences, profile, saved and own reviews and how earlier rounds went. Words come from the Novelty Library catalogue, Open Library, Wikipedia and Datamuse, with book-associated words preferred for part of the rounds, not all.
- **HangLex asks for a book or an author with a single trope clue** (never the author's name). Puzzles come from a built-in set of popular titles and authors, the community's own books, and Open Library subjects.
- **Never the same question twice**: every word/puzzle served is remembered (as a short hash) in the browser and, for signed-in readers, mirrored into their account's `nl_enigma` user metadata, so a new device does not replay old ones. A LexiWord answer stays out for a year; a HangLex puzzle does not return while any unseen one can be found (Open Library is searched further when the built-in set runs out).
- **Look**: gold removed. Teal and cyan in light and dark themes; the hub shows two centred animated icons (a flipping word grid; a gallows with a swinging book), the game name and a one-line brief. The knight tab icon is now a teal/cyan chess knight.
- No database, Supabase schema or backend changes. No SQL needed.
- Build status: not verified with a full `npm run build` in this environment (npm registry unreachable); new files were type-checked against stubs and exercised in Chromium and a Node test.
