# Novelty Library 2.50

Submit form, built on 2.49.

- **Open Library check under Title/Author** (public API at openlibrary.org): after typing pauses, the title and author are checked. A match shows "Matches Open Library" with author, first-publication year and cover; a near-miss shows "Open Library suggests" with **Use these details** and **Use this cover** buttons. Nothing in the form changes unless the reviewer presses a button. Silent when offline or when nothing matches.
- **Pasted / imported reviews**: if a long review is pasted and it opens with "Title by Author", "Review of …" or "Title:/Author:" lines, the empty Title/Author fields are pre-filled and then checked. The review text itself is never touched.
- **Review Helper · Taste Match panel** above the review box: four short points and the button **Polish with Review Helper / Taste Match**, with a change summary, optional tips (very long sentences, repeated openers) and **Undo**. It runs only when pressed, on the device, and Undo disappears once the reviewer types again.
- **Polish** (`src/lib/reviewPolish.ts`) fixes spelling slips, missing apostrophes, capitals, spacing, punctuation, a/an, repeated words, commas after openers like "However" and before "but" joining two clauses, and closes paragraphs with a full stop. It leaves ALL-CAPS emphasis, links, @handles, #hashtags, emoticons, slang and wording alone, and refuses to apply if the result would pass 2000 characters.
- `lookupOpenLibraryBook` (readerTools.ts) now takes an author and returns all authors and large cover; new `src/lib/bookVerify.ts`; `proofreadAndPolishReview` in tmai40Engine.ts now delegates to the new module.
- No database, Supabase or backend changes. No SQL needed.
- Build status: new files checked against stubs and exercised in Chromium/Node; a full `npm run build` was not run here (npm registry unreachable).
