# Novelty Library 2.52

Frontend-only; no SQL. Not built with `npm run build` in the authoring sandbox: run `npm install && npm run build` first.

- `lib/foulCheck.ts`: swearing, slurs and abuse incl. disguises (f*ck, sh1t, @ss, stretched or spaced letters); whole-word matching avoids false hits (class, cockpit, Moby Dick). Strong words alert immediately and block submit; mild language (hell, damn, idiot) shows a soft note only.
- `ReviewHelperPanel` now holds the quality tips and word count (old "Review quality helper" box removed) and sits under the review textarea.
- Mask flagged words is user-triggered and undoable.
