# Novelty Library 2.53

Frontend-only; no SQL. Not built in the authoring sandbox: run `npm install && npm run build` first.

- Accounts & Settings: first row renamed **Account** (shelf label is now "You"); the "?" popover now links to Privacy and Terms, and the same text is in both pages.
- **Sound controls** (was Sounds); "Enigma & games" is now **Enigma Gamespace**.
- **Notifications** split into sections: Reviews (Likes, Comments, Ratings, Replies, Submissions), Stories (Likes, Shares, New stories), Library, Updates. Legacy switches are derived so the database filter still works; old choices carry over.
- **Content preferences** now opens: Manage interests, Muted words, Taste Match.
- **Muted words**: hides matching reviews in the reviews list, Taste Match SE picks, "More like this" and "Read next".
- **Taste Match controls** (per account, all on by default): Profile answers (Personal, Reading), Reviews submitted, Interests managed, Device info, Browser info. "?" popup explains the data is kept only with us and not shared. Honoured by the Enigma signals.
- Muted words and Taste Match controls are stored on the sign-in record (auth user_metadata.nl_prefs); notifications and interests still use the database as before.
