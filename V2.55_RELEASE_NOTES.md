# Novelty Library 2.55

Frontend-only; no SQL. Run `npm install && npm run build` first.

- **Reviewer profile cards**: clicking a reviewer's name opens the same teal/cyan profile card members have, with Follow, Replay, Report, Share, a followers bar, the published shelf and a "Reviews by" list. Works for reviewers without an account (`/reviewer/<id>`) and for `@usernames` whose profile is not public (no more "Profile not found" when they have published reviews).
- **Instagram**: the handle beside the reviewer name on a review page (and the pill on the card) opens that Instagram profile in a new tab.
- **AdSense**: the ad slot only requests an ad when a visible 600+ character review body is on screen; reviewer/profile pages that are loading or unavailable are noindex.
- Follow on reviewers uses the existing author-follow tables with a `reviewer:<id>` key. If the server rejects that key, Follow still works in this browser.
