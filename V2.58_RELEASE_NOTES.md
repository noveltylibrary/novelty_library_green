# Novelty Library 2.58

Frontend-only; no SQL. Run `npm install && npm run build` first.

- Reading goal: no placeholder/default goal any more. The Reading Challenge card appears (for you and visitors) only after you pick a level or type a goal and Save. The editor starts empty and says so.
- Reading goal eye: when it is off, the challenge is hidden from the public profile (you still see it, with a note).
- Content preferences: Manage interests, Muted words and Taste Match now show a "← Content preferences" back link on PC too.
- HangLex: 7 tries instead of 8; the hanging tiles now spell H A N G L E X.
